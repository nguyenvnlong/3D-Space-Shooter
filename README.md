 # 🚀 3D Space Shooter Game (Three.js)

[ English ] | [ 中文 ]

---

## 🇬🇧 English

A 3D space shooter game built with WebGL and **Three.js**. Control your spaceship, dodge obstacles, and destroy asteroids in deep space!

### ✨ Key Features
- **3D Graphics & WebGL**: Smooth rendering powered by Three.js.
- **Infinite Starfield**: Immersive deep space background.
- **Health & Combat System**: Player starts with 3 HP, dynamic collision detection.
- **Random Asteroids**: Procedurally colored and rotating asteroids.
- **Responsive Design**: Automatically adjusts to browser window size.

### 🎮 Controls
- **Left / Right Arrow** or **A / D**: Move Spaceship
- **Spacebar**: Fire Laser
- **R Key**: Restart Game

### 🛠️ Tech Stack
- **HTML5 / CSS3**
- **JavaScript (ES6+)**
- **Three.js** (3D WebGL Library)

## 🇹🇼 中文 (繁體 / 簡體)

基於 **Three.js** 與 WebGL 開發的 3D 太空射擊遊戲。玩家需操控宇宙飛船在浩瀚星空下躲避並擊碎隕石！

### ✨ 核心特色
- **3D 視覺與 WebGL 渲染**：利用 Three.js 提供順暢的 3D 遊戲體驗。
- **動態動態星空背景**：打造沉浸式的太空飛馳效果。
- **生命值與碰撞系統**：飛船擁有 3 點血量（HP），具備精準的 3D 空間碰撞偵測。
- **隨機生成隕石**：每次出現的隕石均帶有隨機色彩與轉速。
- **自適應螢幕**：自動縮放以適應不同的瀏覽器視窗大小。

### 🎮 操作說明
- **方向鍵 左 / 右** 或 **A / D**：移動飛船
- **Spacebar (空白鍵)**：發射雷射
- **R 鍵**：重新開始遊戲

### 🛠️ 使用技術
- **HTML5 / CSS3**
- **JavaScript (ES6+)**
- **Three.js** (3D 渲染庫)
