# 🚀 3D Space Shooter Game (Three.js)

Một dự án Game 3D bắn phi thuyền trong không gian được xây dựng bằng JavaScript thuần và thư viện **Three.js**.

## 🌟 Tính năng chính
- Giao diện 3D render trực tiếp trên WebGL mượt mà.
- Hiệu ứng môi trường vũ trụ chuyển động không giới hạn (Infinite Starfield).
- Hệ thống xử lý va chạm chính xác trong không gian 3D (Collision Detection).
- Tính điểm trực tiếp và hỗ trợ khởi động lại nhanh (Game Reset).

## 🛠️ Công nghệ sử dụng
- **HTML5 & CSS3**
- **JavaScript (ES6+)**
- **Three.js** (Thư viện 3D Rendering)

## 🎮 Hướng dẫn điều khiển
- **Phím Mũi tên Trái / Phải** hoặc **A / D**: Di chuyển phi thuyền.
- **Spacebar (Phím cách)**: Bắn đạn laser.
- **Phím R**: Bắt đầu lại khi Game Over.
